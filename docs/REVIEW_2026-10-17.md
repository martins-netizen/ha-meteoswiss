## Targeted improvements

1. **Bound source access:** station/archive clients accept asset URLs from
   trusted STAC metadata. Shared HTTPS/destination/redirect and response-size
   enforcement is not yet consistent across clients. The catalogue has its own
   size limit. This is hardening work; no concrete exploit was demonstrated.
2. **Analyse external contributions safely:** the reviewed CodeQL workflow
   skips foreign-fork PRs. A skipped job is not analysis. Establish a safe route
   before accepting external code; do not use privileged
   `pull_request_target` execution of untrusted code as a shortcut.
3. **Improve maintenance deliberately:** consider extracting shared time parsing;
   decide separately whether inactive camera/SLF/hydrology placeholders should
   be removed or meaningfully tested. Do not exclude modules merely to raise coverage.

The 30-second limits cover individual requests and some outer budgets, not
every multi-request operation. Long Retry-After values end the current retry
sequence; no cooldown persisting across later scheduled refreshes exists.
