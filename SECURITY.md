# Report a security vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/martins-netizen/ha-meteoswiss/security/advisories/new)
for a suspected vulnerability in this maintained fork. Do not put exploit details
or confidential installation data in a public issue.

Include the affected release or exact commit, Home Assistant version, impact
and the smallest safe reproduction you can provide. Redact tokens, private
addresses, coordinates, account details and unrelated logs. Do not upload a full
Home Assistant backup or test by operating physical devices.

Security fixes target the latest stable fork release. An explicitly announced
prerelease is also in scope while it is being evaluated; older versions may
need an update. This is a community project without a guaranteed response time.

Use the [public issue tracker](https://github.com/martins-netizen/ha-meteoswiss/issues)
for ordinary bugs and feature requests, with relevant redacted evidence. A
provider outage, missing individual value or changed weather forecast can be
reported there without confidential vulnerability details.
